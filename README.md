# moveplay-tv

Static host (GitHub Pages) for a family's two Android TV apps:

- `kids/` — **Move & Play** (camera motion games for kids): APK, `version.json`, and game art/music/voice in `content/`
  (art by Kenney, CC0; music credits in `kids/content/CREDITS.txt`).
- `lyrics/` — **Lyrics TV** app update (no song lyrics are stored here).

The apps only install updates signed with their original key.
